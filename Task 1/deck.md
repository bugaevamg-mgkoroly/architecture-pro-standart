3. Описание кредитного процесса (дополнение к схемам)
Шаги процесса:

Клиент подаёт заявку на кредит:

В отделении (менеджер вносит в АБС).

Через интернет‑банк (в будущем).

АБС передаёт заявку в Кредитный конвейер (раз в сутки).

Менеджер кредитного отдела:

Проверяет данные в Кредитном конвейере.

Запускает скоринг через API.

Система скоринга:

Отправляет запрос в Бюро кредитных историй.

Анализирует данные из АБС.

Возвращает рейтинг заёмщика.

Менеджер принимает решение:

При одобрении → статус передаётся в АБС.

АБС зачисляет средства на счёт клиента (раз в сутки).

Клиент получает СМС‑уведомление.

Узкие места:

Передача данных между АБС и Кредитным конвейером — раз в сутки (задержка).

Ручной ввод данных менеджерами.

Отсутствие онлайн‑скоринга для заявок через сайт.
