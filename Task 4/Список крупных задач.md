## Сфписок крупных задач для каждой системы
**АБС:**

1. Добавить API‑метод для выдачи актуальных ставок и истории.

2. Обеспечить журналирование изменений ставок.

**Сервис синхронизации ставок:**

1. Реализовать опрос АБС каждые 15 мин.

2. Обновить БД кол‑центра при изменениях.

3. Добавить мониторинг задержек.

**Сервис экспорта ставок:**

1. Разработать формирование CSV/XLSX по шаблону.

2. Настроить выгрузку на SFTP (SSH‑ключи).

3. Добавить журналирование и алерты.

4. Развернуться в резервном ЦОД.

**Система кол‑центра банка:**

1. Добавить раздел «Ставки по депозитам» с актуальными данными.

2. Отображать дату последнего обновления.

**SFTP‑сервер партнёра:**

1. Настроить приём файлов с SSH‑аутентификацией.

2. Обеспечить резервное копирование.
